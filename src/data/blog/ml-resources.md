Curated list of good resources for getting into machine learning.
If I wanted to get into machine learning today (which I am), I would look into this:

The dates refer to when the book / course was last updated.

## Books

All of these have free online versions available!

### [Practical Deep Learning for Coders (2022)](https://course.fast.ai/Lessons/part2.html)
Jeremy Howard, Sylvain Gugger


### [Dive into Deep Learning (2022)](https://d2l.ai/)
Aston Zhang, Zachary C. Lipton, Mu Li, Alexander J. Smola


### [Understanding Deep Learning (2025)](https://udlbook.github.io/udlbook/)
Simon J.D. Prince


### [Deep Learning with Python - Third Edition (2025)](https://deeplearningwithpython.io)
François Chollet, Matthew Watson


### [Foundations of Computer Vision (2024)](https://visionbook.mit.edu/)
Antonio Torralba, Phillip Isola, and William Freeman


### [Learning Deep Representations of Data Distributions (2025)](https://ma-lab-berkeley.github.io/deep-representation-learning-book/)
Sam Buchanan, Druv Pai, Peng Wang, Yi Ma


### [The Little Book of Deep Learning (2024)](https://fleuret.org/francois/lbdl.html)
François Fleuret
